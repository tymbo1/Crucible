# C1 diagnostic assessment

Date: 2026-10-21
Scope: read-only analysis of the sealed C0/C1 traces

## Verdict

The C1 result is internally consistent but does not establish an adaptive
policy advantage. Verification-only wins because the fixture supplies a perfect,
immediate verifier at cost 3. Adaptive uses more mean cost and skips that
verifier on the low-confidence shortcut-probe branch.

This diagnoses the current environment and policy branch; it does not disprove
the recursive equations.

The policies shared the same ceilings, but not the same realized cost. C1 was
therefore a matched-budget-ceiling comparison, not a matched-cost efficiency
experiment.

## Why verification-only won

The verifier returned an exact answer immediately in every case. Verification-
only called it for all 256 records, corrected all 153 initially wrong answers,
and committed 256 verified records.

Adaptive called verification only in the clean-correct, contradiction and
misleading-evidence categories. It called it zero times for the 51
shortcut-probe cases. Those cases received critique plus counterexample, but
the synthetic revision rule required two independent error signals; the
critique was `uncertain`, so all 51 remained unresolved.

Adaptive consequently spent more than verification-only while resolving fewer
cases. Its 54 rejected memory attempts are not a correctness failure: the
contradiction/provenance gate correctly prevented unsupported commits.

Fixed-depth's 78.91% result shows that critique/counterexample can correct many
cases, but it cannot handle the misleading-evidence category without an
independent verifier. Confidence-stop is not informative as a calibrated
policy: the synthetic confidence has Brier score 0.3196 and ECE 0.45, and the
policy stops on confidently wrong cases.

## Oracle and fairness assessment

Verification-only did not receive a hidden action unavailable to the other
policies: the verifier was part of the common declared action set. It did,
however, operate in a regime where that action was exact, immediate and always
available. This is an environment advantage for verification-first behavior,
not evidence that verification-only is universally best.

The exact verifier was used by the evaluator and by the explicit `verify`
action only. Ordinary scores recorded no answer quality, fabricated
information gain or current-task self-quality. Information gain remained
unavailable because no calibrated likelihood transition was supplied.

## Task-discrimination assessment

C1 included five deterministic response categories, but it did not vary the
verification contract. It therefore could not test whether a policy adapts to
noisy, expensive, delayed or unavailable verification. The next useful gate is
the separately versioned C1b proposal at:

`experiments/crucible_recursive_controller_c1b_20261021/PROTOCOL.md`

C1b adds a verification-first adaptive baseline and six preregistered tool
regimes. It is proposed only; it has not been executed.
