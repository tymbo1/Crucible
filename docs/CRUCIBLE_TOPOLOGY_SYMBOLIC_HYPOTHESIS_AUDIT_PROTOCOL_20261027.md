Date: 2026-10-27

## Objective

Independently test the mathematical mechanisms proposed in the ProjectBrain /
Selyrion symbolic-space simulations and compare their predictions with the
existing four topology-control checkpoints. No training, checkpoint changes,
new splits or sealed-test access are permitted.

## Symbolic mechanisms to test

1. Structural graph differences: diameter, mean shortest path, triangles,
   bridges, algebraic connectivity and clustering.
2. Diffusion: `H(t) = exp(-tL)` distance from the uniform mixing operator.
3. Exact modular path composition from edge offsets generated by latent node
   potentials.
4. Single-path error propagation after one corrupted edge.
5. Global least-squares reconciliation under one corrupted edge and Gaussian
   edge noise.
6. Effective-resistance identities:
   `E[error^2] = sigma^2 R_ab` for Gaussian noise and `R_ab / m` for one
   uniformly selected unit edge error.
7. A 500-graph degree-matched random-regular control laboratory.

## Neural falsification tests

For every original topology-control validation checkpoint, report pair-level
errors against:

- H1: shortest-path distance;
- H2: effective resistance;
- H3: pair/identifier/seed-specific behaviour and bridge crossing.

These are descriptive tests over eight held-out pairs and failed-gate arms;
they cannot establish a neural mechanism. The neural data are not pooled with
the duration-extension experiment until that run is complete and audited.

## Interpretation boundary

Exact symbolic success establishes logical recoverability for the consistent
modular task, not neural learning. Agreement between effective-resistance
formulae and noisy linear reconstruction establishes a mathematical property
of that reconstruction model, not an implementation inside Crucible. Any
neural correlation is exploratory unless replicated with competence-gated,
structurally discriminating graph controls.
