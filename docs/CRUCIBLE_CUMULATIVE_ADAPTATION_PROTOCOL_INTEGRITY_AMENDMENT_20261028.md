## 1. Target-task dependence and paired inference

The frozen metadata manifest was audited before any target answer was opened:

| Check | Result |
|---|---:|
| Target records, seed 42 | 144 |
| Target records, seed 1337 | 144 |
| Unique target task IDs | 288/288 |
| Cross-seed canonical-AST intersection | 0 |
| Cross-seed truth-table intersection | 0 |

Therefore the same target task does not appear across seeds. The registered
paired unit remains one complete target task within one seed and target family,
with all arm outcomes kept together. The source and operator-validation
procedures are repeated by seed, but they are not target observations and are
not included in the primary denominator.

The target-phase policy state is frozen after source adaptation and operator
validation. No target answer, target verifier outcome or target success flag may
update an arm before all target proposals are finalized. This removes
order-dependent adaptation from the primary comparison.

The primary analysis remains the exact two-sided McNemar test on the 288 paired
task-seed clusters. The confidence interval is a 20,000-replicate stratified
cluster bootstrap: resample complete task clusters within each of the four
`seed × target_family` strata, carrying every arm's outcome together. Arm rows
must never be resampled independently. Seed-level, family-level and
`seed × family` results are reported separately; the pooled result is not
described as four independent replications.

## 2. Zero-promotion interpretation

Promotion remains exactly:

```text
LCB95(Beta(1 + successes, 1 + failures)) >= 0.80
```

With the registered `Beta(1,1)` prior and 16 trials, this requires 16/16
successes. If no eligible operator reaches that threshold, the A3 state must
be recorded as:

```text
mechanism_status = unactivated_inconclusive
```

The result must not be interpreted as evidence against an active verified
learning policy, because no operator was activated. The threshold, trial
allocation and eligibility limit cannot be relaxed after outcomes are seen.
If only one seed or target family activates, the overall cumulative-learning
claim remains supported-but-inconclusive at most and cannot pass the registered
replication gate.

## 3. Frozen deterministic representative grammar pool

The runner uses the committed
`experiments/crucible_cumulative_adaptation_preflight_20261028/GRAMMAR_REPRESENTATIVE_POOL.jsonl`.
Its SHA-256 is:

```text
fc359da2184254b3fe49dc90e8fbbbe91146e475bf10e3b389d9ed98723b40e9
```

The pool is generated by 10,000 deterministic valid-AST draws from the frozen
depth-3, node-7 `digit_expr_mod10_v1` grammar using seed `20261028`. The first
occurrence of each canonical structural AST hash is retained. The pool has
2,730 structural rows and 692 functional representatives. 7,270 repeated
structural draws and 9,308 draws duplicated in the functional-representative
projection are excluded from those respective sets. Invalid or out-of-scope
expressions are never written to the pool.

This is a sampled representative pool, not an exhaustive grammar enumeration.
Expressions not sampled, and functions absent from the sampled functional
projection, are outside the evidence scope. The exact truth table is used only
for predeclared leakage checks and scientific evaluation after proposal
finalization; it is not supplied to the proposer as a target answer.
