# Scientific Interpretation

This run tests whether the original topology-control training failures were caused by insufficient duration. The exact task, data, architecture, optimizer settings and seeds were retained, and the first 500 updates were reproduced from fresh initialization before extending to 2,000.

Interpret validation only for final gate-passing arms. Even if longer training rescues an arm, this does not establish a graph-distance effect; it only makes a later competence-matched topology comparison possible.
